# Changelog

## 1.9.2 — 2026-09-13

- added a mandatory subject-lift gate for dimensional separation from flat collage
- required planar architecture to split into a realistic depth-bearing portal/object and a printed or omitted facade plane
- rejected heroes that remain continuous with an untreated photographic background
- added subject-lift fields to preflight and actual prompt compilation
- validated the new rule on Zhonghua Gate by isolating the arch reveal, open doors and receding tunnel over halftone wall material

## 1.9.1 — 2026-09-13

- added a mandatory thumbnail impact gate after the portable layout lock
- required one singular hero silhouette, one visible scale breach, one source-supported depth event and explicit value separation
- blocked flat results where hero, background and support collapse into one plane
- established a three-scale hierarchy: monumental hero, giant title system and subordinate support fragments
- clarified that symmetrical heritage subjects gain tension through crop, scale, overlap and asymmetric collage contours

## 1.9.0 — 2026-09-13

- made the GitHub package self-contained: users no longer need external layout references
- added automatic R1–R4 selection from hero geometry
- added a bundled reference manifest and text-only normalized blueprints for all four layouts
- defined portable region locks, z-order, allowed crossings and thumbnail checks
- required the generator to attach exactly one bundled master as composition-only input
- clarified that layout subjects, literal copy and decorative objects must never transfer into a new poster
- strengthened axial-gate behavior with a dominant dark tunnel mass and title overlap
- kept all existing replaceable content fields and changed reference defaults to `auto` and `auto-bundled`

## 1.8.0 — 2026-09-13

- consolidated conflicting historical constraints into reference structure plus subtle local collage variation
- required explicit print treatment for every auxiliary layer, including flattened halftone highlights and shadows
- added bounded source-derived or authorized-compatible background ornament
- kept original photography authoritative for hero material
- bundled four layout masters, an outgoing-prompt template and a resolved Ming Xiaoling example
- removed universal whitespace, edge-count and overlap quotas
- preserved existing content fields and added revision-master, variation and ornament controls
- distinguished package checks from mandatory visual acceptance

## 1.7.0 — 2026-09-13

- replaced the generic coordinate-box system with strict tracing of one complete supplied reference structure
- added four independent reference layout IDs: R1 Nine Dragon Wall, R2 Shanhua Temple, R3 Bell Tower, and R4 Huayan Temple
- locked display-title scale and line breaks, left-rail typography, hero territory, secondary image masses, z-order, and negative-space pattern to the selected reference
- prohibited hybrid structures assembled from different references
- established the real source subject as the mandatory first visual center
- allowed reference-matched hero occlusion of title edges and substantial overlap of supporting imagery
- removed universal overlap percentages in favor of matching the selected reference's visible relationships
- restricted creative freedom to source selection, image treatment, collage contours, and replacement copy
- replaced `left_rail_preset` with `reference_layout_id`

## 1.6.0 — 2026-09-13

- changed supplied source images from compulsory inputs to a candidate library
- added selected-versus-unused source recording and one primary visual job per selected source
- expanded allowed source-derived treatments while preserving hero identity and documentary inscriptions
- made substantial halftone context plus a separately processed evidence fragment mandatory
- required mixed collage geometry with no more than one clean rectangular secondary mass and at least two irregular boundaries
- added four selectable left-typographic-rail presets based on the approved reference family
- required one locked rail preset per poster with explicit reading order, alignment, coordinates, and spacing
- added `source_selection` and `left_rail_preset` replaceable fields

## 1.5.0 — 2026-09-13

- converted coordinate zones into strict core containers with explicit minimum containment
- added per-element edge bleed, single overlap target, overlap location, maximum overlap, and z-order requirements
- set default containment thresholds of 90% for text and 88% for image masses
- allowed a declared 5–15% hero overlap on the display-title zone while keeping the title recognizable
- kept local-title and editorial-copy zones unobstructed by default and capped hero coverage of a secondary image zone at 12%
- prohibited one element from entering multiple neighboring zones
- clarified that canvas bleed does not authorize crossing an internal zone boundary
- added a single-reference topology lock so multiple references inform visual language without averaging their spatial maps
- added hard failures for containment and overlap-budget violations

## 1.4.0 — 2026-09-13

- added mandatory coordinate-based layout maps for all text and image zones
- added explicit allowed-overlap and forbidden-crossing declarations
- added three copy modes: `exact-only`, `editorial-nonfactual`, and `none`
- permitted authorized non-factual editorial copy while continuing to block fabricated dates, coordinates, provenance, quotations, institutions, and historical claims
- allowed pre-resolved compositional devices such as rules, dividers, paper bars, numbering, masks, and source-color wedges
- added zone-drift, generic-layout substitution, and unapproved factual-copy failures
- added `copy_mode`, `layout_map`, and `construction_devices` fields without removing existing replaceable content fields

## 1.3.0 — 2026-09-13

- recalibrated the composition from calm sparse collage to dense-but-zoned layered editorial collage
- added an explicit composition recipe and predicted fixation order
- added one large processed structural context plane between title and realistic hero
- separated structural context from smaller evidence-detail fragments
- added three-plane depth and paper-channel requirements
- reduced the calm-area target from 35–50% to a distributed 18–30%
- added three source-led series composition routes
- added optional `composition_route` and `graphic_field` controls without removing any existing replaceable fields
- allowed faint uniform print grain in display type while continuing to reject heavy distress
- allowed one pre-resolved source-color field with a named compositional job while preserving the ban on automatic red circles and decorative motifs
- limited visible type to three hierarchy levels and blocked invented editorial side copy
- added failures for corner-sticker collage, missing middle depth, dead blank fields, and source-independent brush blobs

## 1.2.0 — 2026-09-13

- narrowed the activation boundary to historical and cultural heritage posters
- added a mandatory pre-generation hard gate
- added required-input, source-ledger, whitelist, forbidden-content, and structural-lock checks
- required a resolved preflight record before image generation
- added an exact prompt compilation order
- required unused optional fields to be deleted before compilation
- prohibited open-ended prompt alternatives and style-inferred decoration
- required all whitelisted source images, and only those images, to be attached at generation time
- added result inspection, hard failure conditions, and rebuild instructions
- limited automatic rebuilds to two before returning the unresolved conflict to the user
- preserved the existing replaceable field system

## 1.1.0

- separated fixed visual behavior from replaceable content fields
- added minimal and full input modes
- strengthened giant-title, source-fidelity, quiet-background, and no-fixed-motif rules
