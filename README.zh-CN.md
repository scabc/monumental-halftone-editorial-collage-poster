# Monumental Halftone Editorial Collage Poster

[English](README.md) · 中文

用于历史文化遗产视觉海报的自包含 Codex Skill。它以一个强烈、真实的主体作为第一视觉中心，结合锁定的大标题结构、不规则拼贴、半调网点、印刷质感和有限的穿插关系。

## 如何使用

将整个仓库文件夹复制到 Agent 的 Skills 目录，并保持以下内容与 `SKILL.md` 一起存在：

- `references/`
- `examples/`
- `input-template.yaml`

填写 `input-template.yaml`，或在对话中提供同等信息。Skill 会根据主体类型从内置的 `R1.jpg` 至 `R4.jpg` 中自动选择构图母版，也可以通过 `reference_layout_id` 指定。

新用户只需提供自己的历史文化遗产主体图片和文案，不需要重新寻找本项目使用的构图参考。四张内置海报只用于锁定构图关系，不得当作其他地点的素材来源。

## 核心定位

本 Skill 只服务于历史文化遗产视觉海报，不是通用海报生成器。

它要求：

- 真实主体是第一视觉中心；
- 大标题具有强烈尺度和识别度；
- 文字区、主体区和辅助拼贴区有明确边界；
- 主体可以局部遮挡标题或辅助素材，但不能无控制地大面积越界；
- 主体与平面化辅助层之间必须形成明显的空间、尺度和材质差异；
- 辅助素材必须经过半调、单色、丝网印刷、拓印、木刻或其他明确的平面处理；
- 拼贴既要有结构，又不能全部变成规则卡片或平均分栏。

## 四种内置构图

- **R1 — 长对角建筑型**：适合长墙、连续立面、廊道和横向建筑。
- **R2 — 巨型边缘主体型**：适合佛像面部、雕塑、浮雕、面具和圆形构件。
- **R3 — 中轴门楼型**：适合城门、连续拱洞、塔楼、宝塔和中轴建筑。
- **R4 — 中右竖向主体型**：适合站像、坐像、碑刻、器物和其他纵向主体。

详细坐标、层级关系、穿插范围和缩略图检查标准见 `references/layout-blueprints.md`。

## 强制执行机制

生成前必须通过硬性 preflight：

1. 内容白名单和禁用项已明确；
2. 已选择一个构图母版；
3. 标题、中文竖排、主体及辅助素材区域已锁定；
4. 主体具有清楚的轮廓、尺度突破和空间层次；
5. 所有辅助素材都有明确的印刷化处理；
6. 实际发送给图像模型的 Prompt 已按 `references/prompt-template.md` 编译；
7. 若结果平、散、平均、主体不突出或偏离母版，必须判定失败并重做。

结构通过不等于视觉通过。最终结果必须在缩小观看时仍然先看到主体、再看到大标题。

## 可替换内容

地点名称、英文标题、中文标题、说明文案、主体素材、辅助素材、局部色彩、拼贴边缘和小范围偏移都可以替换。

构图骨架、视觉层级、主体优先级、标题尺度、主要分区和越界上限不能随意改变。
